## いま詰まっていること

**14.4GB の ZIP を Colab の外へ出せない。**

| 経路 | 結果 |
|---|---|
| VS Code のファイルビュー | `Jupyter contents error: 500`。contents API はファイル全体を base64 で JSON に載せるため、このサイズでは成立しない |
| Google Drive（15GB時） | 空き 1.6GB。RLDS 13GB を消しても 15.45GB は入らない |
| Google Drive（100GB化後） | `df` が `Size 100G / Used 100G / Avail 343M`。`Avail` だけ旧クォータのまま。`force_remount` でも解消せず |

**次にやるべき切り分け**: https://one.google.com/storage を開く。

- 「14GB / 100GB」と出る → Drive 側は正常。Colab のマウントの問題なので、新しいランタイムでマウントし直せば解決する見込み
- 「100GB / 100GB」と出る → Google One を購入したアカウントと、Colab がマウントしているアカウントが違う

分割転送の仕組み（`scripts/transfer_large_file.py`）も用意してあるが、Drive が正常化すれば不要。
